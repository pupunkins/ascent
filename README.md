# Моё восхождение

Личный трекер трёх целей-гор (Эверест — Anverse, Килиманджаро — онлайн-школа, K2 — AI-университет) по системе «12 недель», с планом недели и дневником.

## Как устроено

- **`index.html`** — всё приложение в одном файле: разметка, стили (`<style>`) и логика (`<script>`). Чтобы что-то поменять, открой этот файл в любой нейросети (Claude, ChatGPT, Cursor) и опиши, что нужно.
- `manifest.webmanifest`, `sw.js`, `icons/` — нужны, чтобы сайт ставился на телефон как приложение и работал без интернета.

## Где хранятся данные

- **На сайте (GitHub Pages):** в браузере устройства (`localStorage`, ключ `ascent-state-v1`). Синхронизации между устройствами нет. Время от времени сохраняй копию: Настройки → «Сохранить копию».
- **В Claude (artifact):** в аккаунте Claude, синхронизируется между устройствами. Там же работает кнопка «Поговорить с мотиватором».
- Перенос между версиями: «Сохранить копию» в одной → «Загрузить копию» в другой.

## Для нейросети, которая будет дорабатывать

- Один файл, без сборки и зависимостей. Шрифты — Google Fonts.
- Состояние — объект `S`, сохраняется через `save()`. При изменении структуры данных добавляй шаг в `migrate()` и увеличивай `S.v`.
- Экраны: `viewPath` (Путь), `viewWeek` (12 недель), `viewDiary` (Дневник). Перерисовка — `render()`, клики обрабатываются через `data-act` в одном обработчике.
- `window.claude` есть только внутри claude.ai. Вне его приложение работает в автономном режиме (`STANDALONE`), а кнопки ИИ скрыты.
- После изменения `index.html` для сайта поменяй `CACHE` в `sw.js` (например `ascent-v2`), чтобы телефон подтянул новую версию.

## Запуск локально

```bash
python3 -m http.server 8765
```

Открыть http://localhost:8765
